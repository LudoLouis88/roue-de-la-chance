# La roue de la chance

Une roue statique à sept choix, partageable par URL.

## Utilisation

1. Ouvrir la page et cliquer sur « Configurer les 7 choix ».
2. Enregistrer puis cliquer sur « Copier le lien à partager ».
3. Envoyer ce lien : les sept choix sont intégrés à l'URL et tous les invités voient la même roue.

## Déploiement Coolify

Créer une application à partir du dépôt GitHub, branche `main`, Build Pack `Dockerfile`, port `80`, avec le domaine voulu. Aucun volume, base de données ou variable d'environnement n'est nécessaire.
